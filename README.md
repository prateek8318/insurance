# 🛡️ InsureEasy

**InsureEasy** is a responsive landing website for home, health and vehicle insurance. Visitors can browse insurance types and send an inquiry to talk to an expert.

## ✨ Features

- 🏠 Home, ❤️ Health and 🚗 Vehicle insurance sections
- 📝 "Send an Inquiry" modal form (name, email, phone, insurance type)
- 📱 Responsive layout
- 🐳 Dockerfile for one-command deployment

## 🚀 Getting Started

```bash
git clone https://github.com/prateek8318/insurance.git
cd insurance
docker build -t insureeasy .
docker run -p 8080:80 insureeasy
```

Or serve it locally with PHP:

```bash
php -S localhost:8000
```
